# AGENTS.md — iDBLink

## Commands (run from project root)

```bash
pnpm install                          # deps
wails dev                             # dev mode (Vite:5100 + Wails window)
wails build                           # production → build/bin/iDBLink.app/
pnpm test                             # Vitest (jsdom, all frontend tests)
pnpm test:unit                        # unit only
pnpm test:components                  # component tests
pnpm test:hooks                       # hook tests
pnpm test:api                         # API tests
pnpm test:integration                 # frontend integration tests
go test ./...                         # Go backend tests (run from root, NOT go-backend/)
pnpm lint                             # ESLint (flat config in frontend/)
pnpm exec -- tsc --noEmit             # Type check (in frontend/)
pnpm format                           # Prettier (config in frontend/)
```

**`wails` CLI:** `~/go/bin/wails` v2.12.0 — add to PATH or use full path.

## Architecture

Wails v2: Go backend → Wails TS bindings → React 19 frontend. No Rust, no sidecar, no HTTP forwarding.

| Layer | Path | Key files |
|-------|------|-----------|
| Entry | `main.go` | Wails app setup, 38 menu items |
| Backend | `backend/` | `app.go` (~1522 LOC, 50+ binding methods), `db/` (10 drivers), `api/`, `localdb/`, `security.go` |
| Frontend | `frontend/src/` | `api/index.ts` (47 API methods), `components/` (~39), `hooks/` (5), `stores/` (3 Zustand) |
| Bindings | `frontend/wailsjs/` | Generated by `wails dev`, **gitignored** |

**Communication:** Frontend → Go via Wails bindings (`frontend/wailsjs/go/backend/App.*`). Go → Frontend via `runtime.EventsEmit("menu-action", ...)` / `EventsOn`.

**Key quirk:** `backend/app.go` wraps HTTP API handlers via `httptest` (`callHandler` pattern) — unusual but intentional.

## Critical gotchas

- **`ConnectionInput` in Wails TS bindings** is under `backend` namespace: `new backend.ConnectionInput(source)`
- **Wails bindings** (`frontend/wailsjs/`) are gitignored, regenerated on `wails dev`. CI generates fresh.
- **Pre-existing Go test failures** (not caused by your changes): `TestConvertValue/int` (type assert), `TestDropTable/drop_non-existent_table`
- **Floating window feature is no-op** — Wails v2 lacks frontend multi-window API
- **i18n not started** — all UI text is hardcoded Chinese
- **Two Go directories:** `backend/` (real source) and `go-backend/` (stale, contains only `testdata/`). The root `main.go` imports `idblink/backend`. Run `go test ./...` from root.
- **CI workflow is outdated** — `.github/workflows/test.yml` still references `go-backend/` and `src-tauri/` (Tauri migration remnant)

## Test quirks

- Frontend tests in `frontend/src/__tests__/` (20 files, 307 tests)
- All Wails bindings are mocked in `src/__tests__/setupTests.ts`. Mocks exported as named constants — import them directly in test files (e.g., `import { mockExecuteQuery } from '../setupTests'`)
- Vitest config: `frontend/vitest.config.ts`, jsdom env, globals enabled
- ESLint: flat config at `frontend/eslint.config.mjs`, ignores `dist` and `src-tauri`

## Verification order

`pnpm lint` → `pnpm exec -- tsc --noEmit` → `pnpm test` → `go test ./...`
